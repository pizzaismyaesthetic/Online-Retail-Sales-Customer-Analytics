# Online-Retail-Sales-Customer-Analytics
Independent analytics project exploring historical transaction data from a UK-based online retailer (2010–2011), using Python, SQL, Google Cloud BigQuery and Google Looker Studio.

The objective was to analyse sales performance, identify customer purchasing patterns, and uncover revenue trends to support business decision-making.

**Dataset:** [UCI Machine Learning Repository – Online Retail Dataset](https://archive.ics.uci.edu/dataset/352/online+retail)

## Tools & Technologies

- **Python (Google Colab):** Data cleaning, preprocessing and transformation using pandas.
- **SQL (Google Cloud BigQuery):** Data querying, aggregation and analysis.
- **Google Looker Studio:** Interactive dashboard development and data visualisation.
- **Google Cloud Platform:** Cloud-based data storage and analytics environment.

## Project Workflow

1. **Data Cleaning & Preparation**
   - Imported and inspected the raw transaction dataset using pandas.
   - Identified and handled missing values, duplicates and invalid records.
   - Prepared the dataset for subsequent analysis.

2. **Data Analysis using SQL**
   - Queried and aggregated transaction data using BigQuery.
   - Analysed sales trends, product performance and customer purchasing behaviour.
   - Developed customer segments based on purchasing frequency.

3. **Dashboard Development**
   - Connected the processed data to Google Looker Studio.
   - Developed an interactive dashboard with date-range and country filters.
   - Visualised revenue trends, order performance, product sales and customer segments.

## Key Findings

- Generated £10.67 million in positive sales value across 19,960 distinct invoices.
- Identified 872 frequent customers contributing £5.91 million in positive sales.
- Examined revenue distribution across frequent, repeat and one-time customer segments.
- Identified the leading merchandise products and geographical markets by revenue.
